# Plantilla: nueva experiencia

Copiá este archivo (ej. `docs/contenido/borrador-<empresa>.md`), completalo
con tus palabras y pedile a Claude:

```text
/nueva-experiencia docs/contenido/borrador-<empresa>.md
```

No hace falta escribir en inglés ni cuidar el formato: Claude traduce, pule
la redacción y te muestra el borrador antes de tocar el sitio. Lo que dejes
vacío te lo pregunta. Cuando termine, borrá el borrador (la información queda
en `experiencia.md`).
